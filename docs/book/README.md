# Vibe Hash

Vibe Hash is a cryptocurrency where mining is useful work. Instead of guessing hashes, your computer trains real AI models in small pieces. Other miners check every piece, and each block pays for the work that checked out. There's no lottery: an old laptop earns the same per unit of work as a gaming PC.

The network is a **testnet**. VIBE has no market value yet, and the chain may be reset.

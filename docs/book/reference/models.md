# vibehash models

Popular open-weight models to fine-tune (coming), with their size, licence and the GPUs a team would need.

```
vibehash models [-h] [--json] [--refresh]
```

Flags:

- `--json`: machine-readable output.
- `--refresh`: ask Hugging Face again, rather than use what it said in the last day.

Examples:

```bash
vibehash models
```

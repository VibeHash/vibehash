How Vibe Hash runs

Settings are changed from the app's own window; a browser can only look.

When to mine

Pause while I'm gamingHolds mining off while a game or any app is full screen, and carries on a minute after it closes.
Pause on batteryMines only while the laptop is plugged in.
Only when I'm awayMines after min with no keyboard or mouse, and stops when you're back.
